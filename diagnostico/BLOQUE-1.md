# Bloque 1 — Identidad de versión

Este bloque evita que se confunda una copia local antigua, una compilación empaquetada y el código vigente del repositorio.

## Fuente oficial

- Repositorio: `jeffer91/curriculo`
- Rama estable: `main`
- Aplicación: `Curriculo`

## Identificación visible

El menú superior muestra la versión de la aplicación. En Electron, el detalle emergente incluye:

- repositorio esperado;
- versión instalada;
- modo de ejecución;
- carpeta raíz utilizada;
- plataforma;
- versión del puente Electron.

Si una pantalla no presenta este identificador, no corresponde a la versión normalizada por este bloque.
